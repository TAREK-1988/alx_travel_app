# ALX Travel App (Django + DRF)

Backend for a travel listings platform.

## Stack
- Django, Django REST Framework
- MySQL (via `mysqlclient`)
- CORS (`django-cors-headers`)
- Swagger docs (`drf-yasg`)
- Env management (`django-environ`)
- App: `listings`
